# 外网服务检测：第一版

入口：手机首页服务器卡片的「外网服务 → 查看全部」，或「设置 → 外观与显示 → 服务器信息显示 → 外网服务检测」选择服务器。

## 支持的功能

- 20 个内置网站，分为 AI、视频与音乐、社交与通信、开发与下载、搜索与常用。
- 每台服务器独立选择检测项目、自动检测开关和最多四项首页置顶。
- 自定义 HTTP/HTTPS 和 TCP 检测；可编辑名称、分类、地址、2–15 秒超时。
- HTTP 支持 GET/HEAD、是否跟随重定向、预期状态码范围、可选响应关键词。HEAD 不读取响应正文。
- 关键词区分大小写，最多读取 64 KiB 响应；超限返回无法确认，不假定成功。
- 全部所选项目、单项重试和仅重试异常项目；进度与取消。取消后不启动剩余批次，当前有限时长的请求返回后停止。
- 诊断显示请求状态、HTTP 状态码、请求耗时、目标 IP（可获得时）、检测传输方式和时间。目标 IP 是远端网站的地址，不作为服务器出口 IP 展示。
- 网站响应、需要认证、请求被拒绝、限流、服务异常、DNS/TLS/连接/超时错误分别记录。

检测从所选服务器发起。新用户默认选择 Google、GitHub、YouTube、ChatGPT，但自动检测关闭；用户手动启动或者打开自动检测后才发起请求。原有三个检测开关的已开启选择和历史结果继续读取，用户保存新配置后使用每台服务器独立的设置。

## 执行、缓存和兼容性

首页与检测中心共用 Riverpod 生命周期内的队列；每批最多三项。Unix 在一个 SSH 命令中并行，Windows 使用三个独立 SSH 通道，Monitor 使用专用接口并行。不会向手机所在网络发起服务检测。

SSH 首次手动检测会识别服务器系统，并尊重已配置的系统类型。Unix 显式使用 `sh`，Windows 显式启动 PowerShell；检测脚本经 UTF-8/base64 单行 stdin 传入，保留中文关键词，避免默认 cmd 的命令长度和转义限制。

每项请求至少间隔 60 秒。正常结果有效 30 分钟，明确的异常响应有效 10 分钟；限流、5xx、忙和未知结果有效 1 分钟。手动检测绕过结果缓存，仍遵守请求冷却时间。旧结果显示原时间，过期结果在详情中标记「上次结果」。

缓存按服务器、连接信息、观察到的服务器公共接口地址、目标参数和规则版本区分。地址或连接配置变化会清除该服务器的检测缓存，并丢弃正在返回的旧结果。用户编辑目标时丢弃旧目标结果，修改首页置顶则保留原结果和请求冷却时间。

自定义项目和选择保存在现有加密设置存储中；检测观察在现有派生缓存中保存，不改变数据库表结构。删除服务器会清理其配置及缓存。

## Monitor 接口

新增 `POST /api/v1/external-probes`，使用已有 Bearer 登录认证。请求包含 `targets`，每次 1–3 项，例如：

```json
{
  "targets": [{
    "id": "github", "name": "GitHub", "category": "developer",
    "address": "https://github.com/", "protocol": "http", "method": "GET",
    "timeoutSeconds": 8, "followRedirects": true,
    "statusMin": 200, "statusMax": 399, "keyword": ""
  }]
}
```

响应的 `results` 为列表，每项含 `id`、`state`（`reachable`、`rejected`、`unknown`）、`reason`、`checkedAt`、`httpStatus`、`elapsedMs`、`remoteIp` 和 `transport`。

内置服务的目的地址由服务端白名单决定；客户端不能替换内置 ID 的地址。自定义目标 ID 以 `custom_` 开头，任意地址和 TCP 连接需要已有 `remote_access.full_access` 授权及其安全传输条件。关闭该权限的 Monitor 仍可检测内置目录；自定义项返回 `permission`，不影响其他内置结果。

接口限制全局并发为三项、每个登录用户每项服务间隔 60 秒，限制缓存条目数并清理过期记录。旧 Monitor 不支持新接口时，客户端提示升级，不回退到任意命令接口。原 `/service-reachability` 保持兼容。

## 验证

Flutter 单元测试覆盖目录和服务器白名单一致性、输入及命令引用、真实本地 HTTP/关键词/TCP 请求、缓存时效、设置保存、并发去重、取消、旧结果丢弃以及 Monitor 登录与兼容性。Widget 测试覆盖首页入口、返回、搜索、管理、创建自定义项目、320 像素大字体、深色模式及旧首页/设置回归。

Monitor 单元和接口测试使用本地服务，覆盖 HTTP/关键词/TCP、鉴权、完整访问权限、非法请求及限频。

## 后续阶段

当前结果验证基础网站或端口连通性。它不保证账号能使用、API 能完成业务请求、流媒体可播放或地区完整解锁。服务专项地区/验证页面识别、API 凭证、实际出口探测和 IPv4/IPv6 分开检测属于第二阶段。
